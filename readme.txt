== Description ==

Veteria is a warm, caring Full Site Editing theme crafted for veterinary clinics and animal hospitals. Soft teal and cream design with rounded friendly shapes, appointment booking CTAs, service grids, veterinarian team profiles, happy-pet galleries, wellness plan pricing, opening hours, FAQs and emergency callouts — everything a modern vet practice needs to welcome pet parents online.

A clean, modern Full Site Editing (block) theme built with theme.json. Includes multiple page templates, curated block patterns, and style variations. Translation-ready and accessibility-conscious.
