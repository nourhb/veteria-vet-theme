# Veteria 🐾

A warm, caring **Full Site Editing (block) WordPress theme** for veterinary clinics and animal hospitals.

**Design:** soft teal + warm cream, rounded friendly shapes, Playfair Display headings + Inter body.

## Multipage templates

| Template | Purpose |
|---|---|
| `front-page.html` | Hero with booking card, services, story, pet gallery, testimonials, pricing, CTA |
| `page-services.html` | Services grid, wellness plans, FAQ |
| `page-team.html` | Veterinarian profiles |
| `page-about.html` | Clinic story, team, testimonials |
| `page-contact.html` | Appointment form, opening hours, emergency callout |
| `page.html` / `page-wide.html` | Default + wide page layouts |
| `single.html` / `archive.html` / `search.html` / `index.html` / `404.html` | Blog + utility templates |

## Block patterns (13)

hero-booking · inner-hero · services-grid · pets-gallery · team-grid · testimonials · pricing-table · opening-hours · faq · cta-booking · contact-info · about-story · 404-art

## Style variations

- **Default** — teal & cream
- **Forest** (`styles/forest.json`) — deeper pine green alternative

## Photos

14 real photos bundled in `assets/images/` (Unsplash + Pexels, free licenses) — vets with patients, happy dogs, cats and a kitten. No placeholders.

## Notes

- All images are referenced locally via `veteria_img()` — the theme works fully offline.
- Emergency phone line in the header top bar; "Book Appointment" CTA throughout.
- Translation-ready (`veteria` text domain), accessibility-conscious markup.
